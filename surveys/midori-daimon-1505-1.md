### 周辺の地区計画

- **大門地区地区計画**（R7.4.25 決定、大字大門・大字間宮の各一部、約34.2ha）
  - 区画整理廃止に合わせて決定。目標は「戸建て住宅を中心とした低層のまちなみ、緑豊かで閑静な住宅地」の維持。幹線道路沿道は住環境に配慮した土地利用を誘導。
  - 地区整備計画の具体値（用途制限・敷地面積の最低限度・壁面後退・垣さく等）は計画書で要確認。
  - 区域内なら **さいたま市地区計画区域内における建築物の制限に関する条例**（建基法68条の2）で条例化された制限も確認。
  - 地区計画区域内の行為は着手30日前までに **地区計画の届出**（都計法58条の2）。
- **大門下野田地区地区計画**（大字下野田・大字大門の各一部、区画整理と一体）
  - A地区（沿道）：第二種住居地域／B地区（低・中層住宅）：第一種中高層住居専用地域、敷地面積の最低限度 135㎡（B地区）。
  - 区画整理施行地区内の場合、**土地区画整理法76条許可**（形質変更・建築等）が必要。

## 2. 開発許可関係

### ケースA：市街化区域の場合
- 開発区域 **500㎡以上** で都市計画法29条の開発許可（さいたま市は500㎡に引下げ）。
- 500㎡未満でも **さいたま市開発行為の手続に関する条例** による「開発承認」の対象になる場合あり。

### ケースB：市街化調整区域の場合
- 面積にかかわらず開発許可（又は手続条例による承認）の対象。
- 立地基準は都計法34条各号のいずれかへの該当が必要。
- **さいたま市は34条11号・12号の条例区域を定めていない**（3号・5号・13号も基準なし）。いわゆる「区域指定による分家・住宅建築」は不可で、既存宅地・分家住宅・沿道サービス等の個別号への該当性検討になる。
- 建築のみの場合も43条許可。

### 共通する条例
| 条例 | 内容 |
|---|---|
| さいたま市都市計画法に基づく開発許可の基準に関する条例 | 技術基準の強化（住宅系開発の公園等：開発区域面積の6%以上 など） |
| さいたま市開発行為の手続に関する条例 | 事前相談（6条）→ **標識設置**（7条）→ 設置日から **30日経過後** に事前協議申請（8条）。締切は月2回 |
| さいたま市中高層の建築及び大規模開発行為等に係る紛争の防止及び調整に関する条例 | 対象事業区域 **3,000㎡以上** の開発・建築で標識設置・近隣説明（自己居住用、3階以下の戸建て等は除外） |

## 3. その他の関連条例・手続き

| 条例・法令 | 要件・内容 |
|---|---|
| さいたま市みどりの条例（19条 緑化協議） | 29条許可の開発行為、中高層建築、敷地500㎡以上の確認申請建築物等。緑化率：500〜3,000㎡未満 5%、3,000㎡以上 (1−建ぺい率)×0.5 と5%の大きい方 |
| さいたま市景観条例・景観計画 | 一定規模以上の建築物・工作物・開発等で届出。規模基準は「届出の手引き」で確認 |
| 埼玉県雨水流出抑制施設の設置等に関する条例 | **1ha以上** の開発行為等で許可。湛水想定区域の盛土は届出 |
| 文化財保護法（埋蔵文化財） | 周知の包蔵地内なら着手60日前までに届出。大門は日光御成道の宿場（大門宿）があった地域のため、遺跡地図で包蔵地の内外を要確認（文化財保護課） |
| 土壌汚染対策法 | 3,000㎡以上の形質変更で着手30日前までに届出 |
| 宅地造成及び特定盛土等規制法 | 規制区域・許可要否を要確認（開発指導課） |
| 農地法 | 地目が農地の場合、市街化区域は5条届出／調整区域は5条許可（農業委員会） |
